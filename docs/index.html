What does the model think it knows? A latent model of how an LLM updates its beliefs

Javier Fumanal-Idocin

Paper PDF Code GitHub Clue game demo Dungeon demo

TL;DR

An LLM playing a game holds a belief about the hidden state of the game. We read that belief in the recurrent memory of Qwen3.5 (2B, 9B, 27B), compare it with the exact Bayesian posterior, and train an anchored JEPA on the memory to learn how a clue or a move changes it. The departure from Bayes is structured and the same at every size: a negation counts half, the sources weigh nearer each other than stated, the latest clue weighs most. The information to be right is in the state; the update misuses it. The belief is one and held in every layer. The JEPA's prediction error flags unusual input, not wrong answers. In the dungeon only the 27B plays the game, and it breaks a forbidden rule once in 800 games.

Abstract

When an LLM solves a problem it is holding a belief of the state that is updated as new evidence arrives. Prior mechanistic interpretability literature has used linear probes to understand where and how this belief state "lives" inside the model and how it affects its decisions. However, interacting with this belief state or understanding its internal dynamics is still problematic. In this work, first we locate the belief state in two games, a clue game and a text dungeon, where it is well defined and can be intervened, and we compare it with a Bayes-optimal model. Secondly, we use an anchored Joint Embedding Predictive Architecture (JEPA), whose latent is tied to the belief the LLM states, to learn the transition between different moments in the game, and to understand the "world model", or lack of it, of the LLM. Based on its latent space, we are able to understand the effect of each clue and why the LLM shows significant differences with the Bayes optimal solutions. For our experiments, we use Qwen3.5-2B, 9B and 27B.

Two games

The clue game

A secret object has four binary properties. Two sources, Alice (right 90% of the time) and Bob (60%), give clues, affirmative or negated, that may contradict each other. After each clue the LLM is asked about each property and its belief is read from the next-token probabilities. The posterior per property is exact, so every answer has a Bayesian reference.

The dungeon

A text maze in the first person. The LLM reads what it sees along its line of sight, its lives and the torch left, and answers with one move per turn. Fire burns, pits kill, ice slides, and the exit starts out of view. The game has no tractable optimal policy, but the one-step risk of each move is exact, and some moves are plainly irrational: a step into a pit it can see, or into a wall.

    Findings

    • The departure from Bayes is structured. In every model size a negation weighs about half an assertion, the two sources weigh nearer each other than their stated reliabilities, the latest clue on a property weighs most, and a clue moves the belief less the more the model already believes it. These regularities fade with size: the 27B is the first to give a stated 90% source its Bayesian weight.
    • The belief is one, and it is everywhere. Every layer's memory supports the same observer; the belief can be read from any one place and changed only by writing every place.
    • The information is there; the update is not Bayesian. On the turns where the answer misses the posterior, a probe of the early layers recovers it almost exactly. The free numbers of the anchored JEPA hold recency, contradiction and the source, the bookkeeping the LLM uses and Bayes would not.
    • The anchored JEPA forecasts what the actions alone cannot. It beats a model that only sees which clues arrived where the state carries something the clue ids do not give cheaply: the wording for the 2B, the belief itself for the 9B and 27B. Its prediction error flags unusual input, contradiction and convoluted wording, so it monitors what the model reads rather than what it answers.
    • In the dungeon only the 27B plays the game. It reaches the exit in 73% of 100 medium levels without thinking and 82% with the previous turn's thought kept; the smaller models walk into walls until the torch runs out. Its remaining errors are pits on the straight line to a door, which thinking avoids every time.
    • Rule-breaking under pressure is rare and ordered. Given a forbidden word that makes every hazard harmless, the 27B says it once in 800 games, and puts less probability on it the more real the stated harm. A promised reward does not move it; a spent torch does.
